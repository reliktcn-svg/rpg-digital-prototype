# Постоянное хранение сетевых партий

На Render Free база SQLite на локальном диске теряется при замене сервера. Срок в семь суток не защищает временный диск. Производственный сервер использует внешнюю PostgreSQL (Neon Free).

- Секрет DATABASE_URL задаётся в Environment сервиса Render; он не хранится в репозитории, клиенте, документах или логах.
- Build Command: `python3 -m pip install -r requirements.txt && python3 verify_storage_deploy.py`.
- Start Command: `python3 server.py`. Health Check Path: `/api/health`.
- Перед развёртыванием тест создаёт отдельную временную схему, проверяет запись героя/снаряжения/владений/чата, запуск нового процесса из другой папки, срок хранения, повтор nonce, ограничение частоты сообщений и запрет записи заменённому процессу. При провале теста сборка останавливается. Производственные таблицы тест не использует.
- Реальная запись подтверждается только после коммита внешней базы. При ошибке возвращается 503, временная база не подставляется. На Render запуск без постоянного хранилища запрещён.
- При запуске новый процесс восстанавливает комнаты и получает право записи. Старый процесс после замены не может перезаписать новые снимки.
- `/api/health` проверяет доступность внешней базы и возвращает безопасные признаки backend/persistent, без адреса и пароля.
- Начатые партии: семь суток от последнего подтверждённого присутствия участника. Лобби: три часа. Истёкшие комнаты и их чат удаляются по прежним правилам.
- Это защищает от обновлений и обычных рестартов игрового сервера. Квоты бесплатного тарифа, сбои поставщика и удаление самой внешней базы остаются ограничениями сервиса; обещание абсолютной сохранности при любых обстоятельствах не даётся.

Для самостоятельного локального запуска остаётся SQLite. Постоянный диск требует явного RPG_STORAGE_PERSISTENT=1 и корректного RPG_SAVE_DB_PATH на подключённом диске. Не включайте этот флаг на временном диске.
