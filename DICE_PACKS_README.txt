Дополнение к v0.6.94: коллекция независимых оформлений кубиков.
Каждый новый набор добавьте отдельной папкой assets/dice/packs/<id>/.
Старые папки оставьте: все варианты будут доступны в «Журнал → Кубик → Оформление».
Для нового названия измените name в pack.json, сохранив id. Выбор героев не сбросится.
Запускайте через прилагаемый server.py: сервер автоматически перечитывает папки.
Анимация из 0.6.92 сохранена без изменений. Цвета и скорость остаются личными для героя.
Карта и правила игры не изменены. В сервер добавлен только каталог оформлений.
Внешний образец — технический, художественный дизайн создаём отдельно.
Инструкция: docs-dice/INSTALL_IN_GAME.md; формат: docs-dice/PACK_FORMAT.md.
Мастерская: /dice-lab.html; проверки коллекции: /tests-dice/packs.html.
