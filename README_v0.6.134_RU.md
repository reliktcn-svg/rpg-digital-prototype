# RPG Digital Prototype v0.6.134

Точечная правка на основе v0.6.133.

## Что изменилось

После выбора маршрута на **очищенный свободный гекс** или в **стартовый Лагерь ЛГ01** кнопка «Завершить ход» подтверждает этот маршрут и завершает ход без ошибки «Сначала подтвердите выбранное перемещение».

Перемещение фиксируется через существующий механизм: сохраняются пройденное расстояние, игровые эффекты входа и проверка чужих территорий. Если маршрут пересекает чужую территорию, игра сначала требует решить вопрос дани/разрешения, затем завершает ход. На неисследованном гексе правила не меняются.

Обновление не меняет систему NG+ и не реализует отложенные предложения по повышению характеристик героя, предметов и золота за врагов.

## Проверки

- Синтаксис JavaScript и Python: пройдены.
- Тесты `tests-v134/test_end_turn.py`: очищенный гекс, Лагерь, неисследованный гекс, транзит через чужую территорию — пройдены в эмуляции Chromium.
- Регрессия v0.6.133 NG+ и интерфейса экипировки v0.6.131: пройдена в эмуляции Chromium.
- Физические Android и iPhone не проверялись. Сетевой режим с несколькими реальными игроками не проверялся.

## Развёртывание

Заменить файлы проекта на GitHub содержимым ZIP (не загружать ZIP целиком как один файл). Дождаться завершения деплоя сервера. Клиенты с установленным кэшем должны увидеть стандартное окно обновления при новом запуске игры.

**Важно:** Не удалять старую стабильную сборку до успешного тестирования.
