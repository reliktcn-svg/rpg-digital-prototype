# Проверки v0.6.130

- `python -m unittest discover -s tests-v130 -v` — уровни/стоимость всех пяти ступеней для шести героев, серверная проверка, новые изображения, манифест.
- `python -m unittest discover -s tests-v129 -v` — прежние тесты сохранения 24-часовых комнат и оптимизированных изображений (после обновления версии ожидания в test_assets.py).
- Прогоны интерфейса на эмулированном мобильном экране в Chromium включают: инвентарь, пояс, все пять рангов, два артефакта, замену брони, кольцо №244, бонусы всех пяти сетов, +D4 Рассвета, условия D12 меча №334, 2D8 наёмника №332 и запрет завершения хода до движения.
- Настоящая проверка Chrome Android и Safari iPhone по-прежнему обязательна; тесты эмуляции не являются проверкой на реальном устройстве.
- В старом tests-progression/rules.test.cjs есть устаревшее ожидание распределения шансов у Лучника (оно не совпадало с данными уже в v0.6.129). Не меняли игровой баланс ради прохождения этого устаревшего теста.

- `python tests-v130/ui_simulated.py` — воспроизводимый тест игровых сценариев в Chromium без обращения к сети (нужен Python playwright и Chromium).
- `node tests-v130/metadata.test.cjs` — вычисление уровня у старых сохранений.
