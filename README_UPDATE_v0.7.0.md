# RPG Digital Prototype — v0.7.0 Tabletop Alpha

Полная визуальная сборка на основе предоставленной v0.6.70. Один игровой движок для ПК, планшета и телефона. Новых библиотек и изменений сервера не требуется.

## Обновление привычным способом

1. Сохраните резервную копию своей текущей папки проекта. Исходный ZIP v0.6.70 оставьте отдельно.
2. Распакуйте ZIP v0.7.0. В корне архива находятся index.html, app.js, server.py и папка assets.
3. Скопируйте всё содержимое поверх файлов своего проекта, согласившись на замену. Новые tabletop.css, tabletop.js, card-art.js и папки assets/encounters, assets/locations тоже обязательны. Не заменяйте .git, персональные настройки Render или переменные окружения — их в архиве нет.
4. Откройте GitHub Desktop, проверьте изменения, сделайте Commit, затем Push origin. Развёртывание Render выполняется прежним способом.
5. После завершения развёртывания обновите вкладку игры. Все участники партии должны открыть одну новую версию. Если старая вкладка продолжает показывать прежний вид, закройте её и откройте снова; при необходимости выполните жёсткое обновление страницы. Не очищайте данные сайта: локальные сохранения хранятся там.

Сетевой формат, ключ локального сохранения и существующие миграции сохранены. Проверена загрузка файла, созданного исходной v0.6.70. Обновление лучше проводить между партиями: перезапуск сервера при деплое и сохранность его хранилища зависят от ваших существующих настроек Render. Эти настройки сборка не меняет.

## Запуск на своём компьютере

Из папки проекта запустите `python3 server.py` (на Windows также может использоваться `python server.py`). Откройте адрес и порт, указанные сервером; по умолчанию http://localhost:8080. Для сетевой партии используйте этот сервер, а не двойной щелчок по index.html. Параметр PORT работает как раньше.

## Управление

- На ПК панель действий находится слева, на телефоне — под полем. Очередь героев на узком экране прокручивается по горизонтали.
- Масштаб карты меняется кнопками +/−. Кнопка ◎ возвращает вид к активному герою. На ПК карту можно перетаскивать мышью, на телефоне — прокручивать касанием.
- «Герой» и «Инвентарь» открывают планшет; крестик закрывает его. «Журнал» открывает историю партии. Сохранение, загрузка и настройка анимаций находятся в «Настройках».
- Переворот предмета или добычи показывает описание. Получение и выбор выполняются отдельными кнопками.
- Постоянные локации открываются с иллюстрацией и действующими кнопками. У святилища можно раскрыть все исходы; у портала «Рассмотреть карту» не выбирает выход. Тёмный вариант торговца и святилища соответствует провалу исходной проверки.
- События, ловушки и специальные карты: широкий формат примерно 21:10 на ПК, рисунок сверху и описание снизу на телефоне. Длинное описание на ПК прокручивается внутри текстовой области, на телефоне прокручивается окно целиком.

## Откат

Для Git-проекта отмените коммит обновления через GitHub Desktop либо верните сохранённую копию v0.6.70. Для чистого отката распакуйте исходный ZIP в отдельную папку: простое копирование старых файлов поверх новой папки оставит новые неиспользуемые файлы. Не очищайте localStorage и серверное хранилище комнат.

В разработке сохранены отдельная копия исходников, Git-метка baseline-v0.6.70 и контрольные коммиты. Исходный пользовательский архив не изменялся. Автоматический push и обновление Render не выполнялись.
