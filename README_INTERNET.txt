RPG Digital Prototype v0.6.1 — Internet Lobby Alpha

ЦЕЛЬ ЭТОЙ ВЕРСИИ
Игроки могут подключаться к одной комнате через обычный интернет:
- 4G/5G;
- домашний/общественный Wi‑Fi;
- разные сети;
- игроки могут находиться в разных местах.

Для этого сервер должен быть размещён в интернете по HTTPS.
Локальный Mac после публикации сервером игры не является.

ЧТО УЖЕ РАБОТАЕТ
- создание комнаты;
- 6-значный код комнаты;
- до 5 игроков;
- имя игрока;
- выбор героя;
- блокировка занятого героя;
- запуск комнаты хозяином;
- мобильный интерфейс/PWA из v0.6.0.

ЧТО ЕЩЁ НЕ СИНХРОНИЗИРОВАНО
На этом alpha-этапе после запуска комнаты сама партия (карта, маршруты, территории,
ходы, бой, тайники, инвентарь и т.д.) ещё остаётся локальной. Это следующий этап.

ПОДГОТОВКА К ПУБЛИКАЦИИ
В комплект добавлен render.yaml. Сервер уже:
- слушает 0.0.0.0;
- использует переменную окружения PORT;
- имеет /api/health;
- раздаёт клиент и API с одного HTTPS-домена после публикации.

Для тестового публичного размещения можно использовать Render Web Service.
После публикации игроки открывают одну HTTPS-ссылку на любом телефоне,
независимо от того, подключены они по 4G/5G или Wi‑Fi.
