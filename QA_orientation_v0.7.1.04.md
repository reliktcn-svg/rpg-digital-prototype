# Проверка ориентации v0.7.1.04

Вертикальный экран: одна колонка. Горизонтальный: боковые действия, карта справа, герой и исследования в две колонки. Ширина героя/инвентаря до 650px, на узком экране ограничена доступным местом.

Проверены девять размеров рабочей области из предыдущего мобильного отчёта. Для каждого проверены шесть героев, семь категорий исследований с длинными описаниями и тремя тестовыми кнопками, окно боя и святилище. Рамки находятся внутри рабочей области, кнопки доступны прокруткой, характеристики находятся внутри портрета, описания способностей помещаются. После правки боковой панели отдельно повторены три горизонтальных профиля; после уплотнения шапки повторён самый короткий 594×368.

При открытом окне героя выполнен поворот 594×368 → 368×594 → 594×368. Окно сохранилось, одна и две колонки переключились, раунд, герой, здоровье и позиция остались прежними. Нативной прокруткой просмотрены нижние блоки героя; вкладки остались сверху.

Горизонтальные кнопки уплотнены до минимальной высоты 40px, подписи действий 13–16px. Короткая высота экрана предполагает вертикальную прокрутку; всё содержимое сразу в экран не сжимается.

Метод: Safari с iframe заданного размера. В отдельной тестовой копии включались ветки CSS для сенсорного экрана, а анимации завершались перед замерами. Это проверка компоновки, не аппаратная проверка Android/iOS. Системные панели и вырезы физического телефона не воспроизведены полностью. В релизе нет тестового запуска и подмены указателя.

Автоматические проверки verify-release.cjs, test_combined.cjs, test_combat_restore.cjs пройдены.
