# Добавление кубиков: отдельная папка для каждого оформления

## Один раз

Используйте подготовленную сборку `RPG_Digital_Prototype_v0.6.94_Dice_Collection.zip`. Она добавляет поддержку каталога к вашей актуальной 0.6.94, сохраняя анимацию 0.6.92. Исходные старые сборки сами искать папки не умеют. Если позже появится более новая сборка игры, сохраняйте в ней эту поддержку: не заменяйте новую игру старым архивом.

Перед переходом экспортируйте важную партию штатной кнопкой «Сохранить». Распакуйте сборку отдельно и запустите её `python3 server.py`. Используйте тот же адрес и порт для доступа к сохранённым в браузере личным настройкам. При необходимости импортируйте сохранение партии. Для первого запуска новой версии сервера перезапустите прежний процесс; новые наборы после этого перезапуска не требуют.

## Каждый новый кубик

1. Получите ZIP оформления из чата о кубиках и распакуйте его.
2. Скопируйте отдельную папку набора в `assets/dice/packs/` актуальной игры. Например, `steel-enamel/`. Остальные папки оставьте на месте.
3. Откройте или закройте и снова откройте **Журнал → Кубик → Оформление**. Новый вариант появится автоматически рядом с прежними. Можно также обновить страницу.
4. Выберите его для своего героя. Скорость и цвета рамки, фона и цифр остаются личными настройками героя.

Не нужно менять JavaScript, каталог вручную, номер версии или пересобирать игру. Сервер перечитывает папки при открытии меню. Новое оформление не включается всем автоматически — каждый игрок выбирает его сам.

```text
папка-игры/
  server.py
  dice_pack_catalog.py
  assets/dice/packs/
    studio-sample/
      pack.json
      ...
    steel-enamel/
      pack.json
      d20-face.png
      d20-rim.png
    obsidian/
      pack.json
      d20-face.png
      d20-rim.png
```

Готовый ZIP содержит путь `assets/dice/packs/<id>/`. Можно копировать только его последнюю папку в `packs`. Не оставляйте ZIP нераспакованным, не создавайте лишнее вложение `assets/assets` или `steel-enamel/steel-enamel`. У каждого НОВОГО оформления своя папка и уникальный `id`; уже существующую папку заменяют только при обновлении этого же оформления.

## Как поменять название уже установленного кубика

В его `pack.json` измените только значение `name`, например:

```json
{
  "format": "rpg-dice-skin-v1",
  "id": "steel-enamel",
  "name": "Рубиновая сталь",
  "faces": {
    "20": {"face": "d20-face.png", "rim": "d20-rim.png"}
  }
}
```

Сохраните файл UTF-8 и снова откройте меню кубика. Новое название появится в «Оформлении». `id` оставьте прежним: именно по нему игра помнит выбор каждого героя. Имя папки и изображения переименовывать не нужно. Можно использовать русское название до 80 символов. Название меняется для всех, кто получает этот набор с сервера; выбранные цвета и скорость не сбрасываются.

## Где лежит актуальная игра

При локальном запуске — папка, из которой работает `server.py`. Если игра на сервере, добавьте набор в папку игры НА СЕРВЕРЕ. Тогда он станет доступен и ПК, и телефонам. Копирование в «Загрузки» телефона сайт не меняет.

Автоматический поиск реализован в прилагаемом Python-сервере и `serve-lab.py`. `python3 -m http.server`, открытие через `file://` и обычный статический хостинг без `/api/dice-packs` каталог не предоставляют. Для другого хостинга нужен совместимый серверный обработчик этого адреса. Не обещайте автоматическое перечисление папок средствами одного браузера.

## Если оформление не появилось

Проверьте `assets/dice/packs/<id>/pack.json`, уникальность `id`, имена слоёв и их регистр. Папка и ID — строчные латинские буквы, цифры, дефис или подчёркивание (1–64 символа, первый — буква/цифра). Слои — PNG/WebP ровно 1024×1024. В открытом меню показываются ошибки. Один повреждённый набор не убирает остальные. Если файл обновлён с ошибкой, до перезагрузки сохраняется последний успешно загруженный вариант. Удалённый набор становится недоступным; его выбор запоминается и восстанавливается при возвращении папки с тем же ID.

В сборке сохранены три прежних оформления и «Свои цвета», а также один технический образец текстур. Художественные наборы создаём отдельно.
