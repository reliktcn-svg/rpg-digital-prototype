# Скины кубиков

Игрок: «Журнал» → «Кубик». Можно выбрать анимацию, скорость и скин, затем посмотреть пробный бросок. Сохранение автоматическое, на текущем устройстве. Настройки хранятся отдельно по ID героя (ключ rpg-dice-preferences-v2), применяются только к его броскам и со следующего броска. Онлайн меню принадлежит локальному герою, в локальной партии — текущему. Профиль фиксируется при открытии меню, владелец и цвета броска фиксируются до постановки в очередь. Враги используют стандартный кубик. Старые общие настройки v1 не копируются всем героям. Пробный бросок не влияет на состояние партии.

Разделение файлов:
- `arcana/dice-motion.js`: перемещение и углы поворота, без цветов и текстур.
- `arcana/dice-renderer.js`: геометрия и отрисовка граней, без определения результата броска.
- `arcana/dice-skins.js`: палитра, рамка, шрифт и текстура поверхности.
- `arcana/dice-animator.js`: время, последовательность кубиков, пропуск, изменение скорости.
- `arcana/dice-settings.js` / `.css`: локальные предпочтения и меню в журнале.

Чтобы изменить вид существующего скина, достаточно редактировать его описание в `dice-skins.js`. Анимация не меняется. Встроены `classic`, `satin-red`, `worn-crimson`. Два красных варианта — программные варианты оформления, а не наложение изображения целого кубика.

Пример своего скина:

```js
FantasyDiceSkins.register('my-skin', {
  face: [114, 21, 33],
  rim: ['#636464', '#25292b', '#424649', '#14191b'],
  number: '#f2eee5',
  numberSelected: '#fffaf0',
  numberOutline: '#381117',
  font: 'Georgia, serif',
  grain: 0.04,
  wear: 0.12
});
```

Новый материал можно передать в `dice.setSkin(id)`. Меню содержит три готовых оформления и «Свои цвета». Для рамки, фона и цифр доступно по 15 цветов; настройки не изменяют общие материалы. Пользовательские материалы получают ID из комбинации цветов, поэтому редактирование не меняет уже начавшийся бросок.

## Текстура из файла

Нужна плиточная текстура материала без цифр, рамки, перспективы и запечённой тени. Цифры рисуются отдельно, поэтому результат остаётся читаемым. Поддерживаются форматы изображений браузера, например PNG, WebP и JPEG. Файл лучше хранить в `assets/dice/` рядом с игрой; для внешнего URL сервер должен разрешать CORS.

```js
await FantasyDiceSkins.load('worn-crimson', {
  ...FantasyDiceSkins.get('worn-crimson'),
  textureUrl: 'assets/dice/crimson.webp',
  textureOpacity: 0.65
});
```

Этот код заменяет материал существующего скина после успешной загрузки изображения. Его можно добавить в конец `dice-skins.js` без `await`, с обработчиком `.catch(console.warn)`: до загрузки будет видна встроенная палитра, после — текстура. Ошибка загрузки сохраняет прежний материал. Для работы офлайн добавьте путь новой текстуры в `ASSETS` файла `sw.js`.

Текстура закреплена в локальных координатах грани и поворачивается вместе с ней. Угол, направление, количество оборотов, скорость и результат от скина не зависят.

Для отдельного экземпляра визуализатора:

```js
const dice = FantasyDice.create({container, skin: 'worn-crimson', speed: 1, motion: 'bounce'});
dice.setSkin('satin-red');
dice.setSpeed(2);
dice.setMotion('roll');
```

В игре текущий бросок использует снимок настроек на момент запуска. Изменения меню относятся к следующим броскам, чтобы время автоматических переходов боя оставалось согласованным.
