# RPG Digital Prototype v0.6.132 — исправление скроллинга Android

База: v0.6.131. Изменена только структура прокрутки мобильного окна «Герой / Инвентарь», плюс номер версии и метаданные Smart Cache. Все игровые механики сохранены.

## Причина

Правило `ui-v06108.css` для `#sheetDrawer:not([hidden])` задавало `display:block!important` и `overflow-y:auto!important`, хотя `styles.css` строил внутренний `.sheet-content` как flex-элемент с собственной прокруткой. На маленьких экранах вместо внутренней прокрутки прокручивался внешний контейнер; сенсорные события отдельных Android-браузеров могли плохо переноситься к нему.

## Исправление

Новый `mobile-scroll-v132.css` делает мобильный `#sheetDrawer` flex-контейнером без внешней прокрутки и оставляет `#sheetContent` единственной вертикальной областью прокрутки. Заголовок остаётся неподвижным. Внутренние горизонтальные ряды предметов сохраняют жесты pan-x.

## Тестирование

В эмуляции Chromium с реальными стилями проекта и тестовым длинным содержимым: для ширины 320, 360, 390 и 393 CSS px после патча внешняя область не имеет дополнительной прокрутки; внутренняя получает scrollHeight > clientHeight. Проверено прокручивание пальцем через CDP Input.dispatchTouchEvent в макете на 360 px. Синтаксис JS проверяется отдельно. Это не аппаратный тест на realme Note 60x RMX3938 или других телефонах. Из-за ограничений среды открыть полноценную игру в Chromium через localhost не удалось (net::ERR_BLOCKED_BY_ADMINISTRATOR).

## Ручная проверка

1. Установить эту сборку на отдельный тестовый сервис и открыть её с realme RMX3938 через Chrome в вертикальной ориентации.
2. Начать тестовую соло-партию, открыть «Герой». Свайпнуть по характеристикам, способностям; убедиться, что список движется и заголовок остаётся на месте.
3. Открыть «Инвентарь». Свайпнуть по экипировке, рюкзаку, замене предметов; проверить горизонтальную прокрутку изображений и нажатия.
4. Повторить в PWA, горизонтальной ориентации, а также на iPhone 11/16 Pro и POCO C85.
5. Убедиться в новой версии v0.6.132; если браузер сохранил предыдущие файлы, использовать штатное окно обновления, а не очищать данные сайта (чтобы не удалить локальные сохранения).
