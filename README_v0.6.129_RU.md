# RPG Digital Prototype v0.6.129 — Mobile Optimization & Persistent Saves

**База:** пользовательский архив `v0.6.128 Smart Cache & Incremental Updates`. Исходный архив не изменён.

## Сделано

- **Графика:** 131 крупных PNG (97 изображений предметов, 33 изображения боссов, 1 изображение карты) преобразованы в WebP; пути обновлены в HTML/JS. Совокупный размер этих файлов: **257,38 MiB → 30,30 MiB** (сокращение на **88,23%**). Оригиналы остались в исходном архиве v0.6.128, но не дублируются в новой сборке.
- **Кэш:** существующая система Smart Cache дополнена ограниченной фоновой предварительной загрузкой статических изображений. Уже проверенные и сохранённые изображения повторно не скачиваются. Частичные обновления и окна новой версии сохранены.
- **Android/мобильное управление:** CSS-исправления сенсорного скроллинга инвентаря и отключение нежелательного браузерного увеличения двумя пальцами без блокировки однопальцевой прокрутки. Требует проверки на реальном Android/iPhone.
- **Соло:** два локальных слота IndexedDB на конкретном устройстве и в конкретном браузере; первоначальный выбор и подтверждение перезаписи, затем автосохранение; экспорт и импорт JSON, восстановление основных игровых данных и положения карты. Соло-данные не отправляются серверу.
- **Сетевая игра:** серверные снимки комнат в SQLite; восстановление с исходными секретами участника; 24 часа с момента последнего игрового действия, без продления heartbeat; экран ожидания других игроков; старая трёхчасовая давность остаётся только для не начатых комнат.

## Самое важное — ограничение Render Free

По умолчанию серверная база сетевых снимков хранится **вне публичной папки игры** во временном каталоге, с правами 0600. Это необходимо для защиты игровых данных от прямой загрузки. **Но диск Render Free временный.** После рестарта/деплоя данные могут быть потеряны, даже если не прошло 24 часа.

Для действительно надёжного восстановления на 24 часа необходимо разворачивать приложение с **постоянным диском** и указывать переменную окружения:

`RPG_SAVE_DB_PATH=/путь/к/постоянному/каталогу/network.sqlite3`

Этот путь должен указывать на **непубличный** и сохраняемый при деплоях каталог вне директории с игрой. Поддержка удалённой SQL-БД в данной сборке **не** реализована, поэтому одна только переменная `DATABASE_URL` не создаст устойчивого хранения на Render Free. Перед настройкой постоянного диска не считать 24-часовое восстановление после перезапуска гарантированным. В течение непрерывной работы сервера сохранение в SQLite и восстановление комнат реализованы.

## Развёртывание

1. Сохранить исходный архив v0.6.128 для отката.
2. Загрузить содержимое ZIP v0.6.129 в корень **существующего** GitHub-репозитория, сохранив структуру, и удалить из GitHub старые PNG, которые в v0.6.129 заменены WebP. Не оставлять оба формата: это сведёт на нет экономию.
3. Остальные настройки Web Service не меняются: Build Command `python3 -m py_compile server.py`, Start Command `python3 server.py`.
4. Дождаться успешного деплоя и появления v0.6.129 в игре. Если браузер показывает окно обновления, завершить скачивание и нажать «Перезагрузить игру».
5. На одном Android проверить обычную прокрутку инвентаря **по содержимому**, не по полосе; на iPhone — отсутствие регрессий. Проверить оба соло-слота и экспорт/импорт.
6. Сетевые комнаты после обновления проверять вместе с двумя реальными участниками. Для гарантии переживания рестарта нужен постоянный диск; на Render Free такой гарантии нет.

## Что проверено

- Проверка синтаксиса Python/JavaScript.
- Девять автоматических тестов: структура графики, наличие файлов, 24-часовое истечение, отличие активных действий от heartbeat, восстановление и приватность серверных снимков.
- HTTP-тест: комната из двух игроков, выбор героев, старт, сохранение и восстановление состояния после перезапуска локального Python-сервера.
- Эмуляция окна выбора соло-слотов в Chromium, с имитацией IndexedDB: сохранить слот и загрузить обратно.

## Что НЕ проверено на реальном устройстве

- Настоящая IndexedDB в Chrome/Safari с долгосрочным хранением и ограничениями iOS.
- Service Worker, фоновые загрузки и обновления на смартфоне.
- Реальные жесты прокрутки Android и запрет масштабирования на iPhone/Android.
- Реальная мультиплеерная сессия с двумя телефонами, всеми боевыми и торговыми ситуациями.
- Длительное хранение 24 часа и деплой Render Free с фактическими потерями/сохранением данных.

Ни одна из этих непроверенных функций не должна считаться подтверждённой тестированием на устройстве. Перед публикацией для игроков рекомендуется тестировать сборку на отдельном тестовом сервисе Render или сохранить ZIP для быстрого отката.
