Сердце тьмы v0.7.1.10

Запуск: распаковать архив целиком, выполнить python3 server.py, открыть http://localhost:8080. Не открывать index.html двойным щелчком для сетевой игры. Порт задаётся PORT. Для телефона/PWA нужен HTTPS.

Сохранения соло: первый раз выбрать слот в Настройках. Затем он обновляется автоматически только после полностью завершённого действия, до нового броска движения. В темнице, во время движения, боя и неразобранных наград запись заблокирована. Экспорт/Импорт слотов позволяет перенести данные на другой адрес сайта или устройство.

Сеть: «Мои партии» сохраняет доступ к нескольким комнатам на этом устройстве. Начатые партии хранятся 7 суток от последнего подтверждённого присутствия участника; точная дата указана в карточке. Незапущенное лобби хранится 3 часа. Просмотр карточки не продлевает срок.

На Render используется внешняя постоянная база PostgreSQL: DATABASE_URL хранится только в секретных настройках сервера. При недоступной базе сервер не создаёт временную замену. Подключение и проверка перезапуска описаны в DURABLE_STORAGE_SETUP.md. Локальный запуск без DATABASE_URL использует SQLite; это режим разработки, без гарантии сохранения после замены хостинга.

Чат и голосование находятся в Журнале. Поддержка автора — на главной и в Настройках. Протокол 2; обновить необходимо сервер и всех участников.

Изменения и границы проверки: CHANGELOG_v0.7.1.10.txt. Тесты: python3 -m unittest test_retention.py test_party_voting.py; node test_combined.cjs (если установлен Node.js).

Обновление значка iPhone: если старый RPG-значок остался, сначала экспортируйте соло-слоты в Настройках, затем повторно добавьте обновлённую игру из Safari. Удаление установленного приложения может удалить локальные данные.

Краткое обучение находится в Настройках. Текст для редактирования — Обучение.md.
